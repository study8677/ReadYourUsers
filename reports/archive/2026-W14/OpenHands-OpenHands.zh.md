### 1. UI/UX Quality Improvements and Bug Fixes

Users are requesting various bug fixes and quality improvements across the application's user interface, including fixing message duplication, display issues with the think tool and repository picker, and message handling during status transitions. Additionally, users want UX enhancements like reducing comment clutter in integrations and new observability features such as per-conversation diagnostics and a scheduled automations management page.

### 2. Security Guardrails for Agent Actions and Dependencies

Users want built-in security guardrails to control AI agent behavior and protect against threats. This includes policy-based controls using OPA (Open Policy Agent) to govern what actions agents can execute, as well as supply chain protections like minimum dependency age checks to prevent attacks from newly published malicious packages.
